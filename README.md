# Business OS — Intelligent Operational Command Center

> An operating system for small and growing businesses that understands what is happening, identifies what needs attention, and helps the owner execute the next action.

Business OS is not accounting software, a CRM, or a project management tool. It sits above individual systems and connects business information into one unified operational view.

---

## ⚡ Key Highlights & Features

### 1. 🏠 Master Dashboard ("What matters right now?")
* **Actionable Focus**: Real-time morning operational greeting and attention badge displaying the exact number of bottleneck items requiring attention.
* **KPI Widgets**:
  * **Revenue**: `₹4.82L` (↑ 12.4% vs last month)
  * **Cash Flow**: `₹1.34L` (Healthy · ₹8.7L reserve, 7.4 months runway)
  * **Customers**: `248` (↑ 8.2% account growth)
  * *Clicking any widget navigates directly to that domain's deep-dive view.*
* **Customizable Widget Manager**: Drag/reorder (Up/Down), toggle visibility (Hide/Show), and reset to default layouts.

### 2. ⚡ Today / Operational Command Center
Replaces passive to-do lists with operational triage cards:
* 🔴 **Critical**: `₹84,000 invoices are overdue` → Review invoices, send AI reminders, or mark paid.
* 🟠 **High Priority**: `Acme hasn't been contacted for 5 days` → AI drafts follow-up email.
* 🔵 **Upcoming**: `Client Strategy Meeting — 2:30 PM` → Instant executive briefing with talking points.
* 🟣 **Decision**: `3 expenses require your approval` → 1-click approval or rejection queue with anomaly detection.

### 3. 🛡️ Evidence-Backed Business Health Matrix
Every metric is backed by deterministic facts:
* **Revenue**: `↑ Healthy` (96.4% target achievement)
* **Cash Flow**: `→ Stable` (7.4 months liquid runway buffer)
* **Customers**: `↑ Growing` (0.8% churn rate)
* **Sales Pipeline**: `↓ Needs Attention` (3 stagnant deals >7 days)
* **Expenses**: `↑ Increasing` (Marketing +31% variance)
* **Receivables**: `⚠ Attention` (₹84k overdue across 4 invoices)
* **Operations**: `✓ Normal` (94.2% SLA completion)

### 4. 💰 Finance Domain & Treasury
* **Financial Snapshot**: Revenue (`₹12.4L`), Expenses (`₹7.2L`), Net (`₹5.2L`), Cash (`₹8.7L`), Receivables (`₹2.4L`), Payables (`₹1.1L`).
* **Interactive Dynamic Visualizations**:
  * Revenue vs. Expenses Area Chart
  * Receivables Aging Buckets (`0-15d`, `16-30d`, `31-60d`, `60+d`)
* **1-Click Batch Chaser**: Dispatches recovery reminders for overdue accounts.

### 5. 👥 Customers & Sales Pipeline Kanban
* **Accounts Hub**: Account health score gauge (`0-100%`), LTV revenue, open invoices, and filter pills.
* **Visual Sales Pipeline**:
  $$\text{LEADS (₹2.4L)} \longrightarrow \text{QUALIFIED (₹4.1L)} \longrightarrow \text{PROPOSAL (₹6.8L)} \longrightarrow \text{NEGOTIATION (₹3.2L)} \longrightarrow \text{WON (₹18.4L)}$$
* **Automated Stagnation Detector**: Alerts on deals with no activity >7 days.
* **Customer Profile Slide-Over Drawer**: Account overview, invoices, deals, team touchpoint log, and AI follow-up generator.

### 6. ✅ Outcome-Linked Work Management
Connects day-to-day tasks to commercial results:
$$\text{Task} \longrightarrow \text{Customer} \longrightarrow \text{Deal} \longrightarrow \text{Invoice} \longrightarrow \text{Revenue}$$

### 7. 🤖 AI Intelligence & 6-Level Permission Framework
Strict human-in-the-loop governance:
$$\text{Level 1: READ} \to \text{Level 2: SUGGEST} \to \text{Level 3: PREPARE} \to \text{Level 4: ASK APPROVAL} \to \text{Level 5: EXECUTE} \to \text{Level 6: AUTONOMOUS}$$
* Real-time proactive insights for Receivables, Sales Accelerators, Expense Anomalies, and Runway Projections.

### 8. 🔔 Centralized Alerts
Triages alerts using three core questions:
1. **What happened?**
2. **Why does it matter?**
3. **What can I do?**

### 9. 🔌 Canonical Integration Architecture
* **Connected**: Google Calendar, Gmail, Stripe Payments, Razorpay & UPI, Open Banking APIs, Slack.
* **Canonical Ingestion**:
  $$\text{External System} \to \text{Connector} \to \text{Raw Data} \to \text{Validation/Dedupe} \to \text{Canonical Business Model} \to \text{Business OS}$$

### 10. ⌘ K Global Search & Universal + Create
* **`Cmd + K` Command Palette**: Instant fuzzy search & natural language intent interpretation.
* **Universal `+ Create`**: Multi-entity forms with deterministic validation & **AI Natural Language Fast Create**.

## 🚀 Getting Started

### Prerequisites
* Node.js (v18+)
* npm (v9+)

### Installation
```bash
# Clone the repository
git clone https://github.com/Pradumnsaindane/Look-Through.git

# Navigate to project folder
cd Look-Through

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
